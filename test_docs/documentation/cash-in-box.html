See exactly how much cash is sitting in every machine right now, so you know what to collect before a box fills or a game gets blocked.

Introduction

The Cash in Box report is a live snapshot of the money currently inside your acceptors — the coin-in each machine has logged since its last confirmed collection and that has not yet been counted. It answers a single, practical question: where is the cash, and how much is there right now?

This is a snapshot, not a date range. There is no date filter — the report always shows the current state. The window for each machine is "from its last confirmed collection until now". A machine that has never been collected shows everything it has ever logged.

Opening the report

Go to Analysis → Cash in Box. Pick a location (or leave it on all), and press Show. That's the only filter — because the report is always "as of now".

Reading the numbers

The top row summarises everything currently in the boxes for your selection: the total amount, the number of coins, how many machines and locations hold cash, and how many coins are unpriced.

Below that, the same money is broken down three ways:

By location — total cash waiting at each shop. This is what you compare against a shop's collection threshold.

By game — cash grouped by game across its machines, so you can see which titles fill up fastest.

By machine — the detailed list, biggest box first. This is the "what to collect" list. Each row shows the amount inside, the coin count, and since when it has been accumulating. Click a row to open that machine's full report.

"Never collected". A machine tagged this way has no confirmed collection on record, so its figure covers its entire history, not just recent activity. Confirm a collection for it and the report will start counting from that point onward.

Unpriced coins. A machine may show a small number of coins with a "+N?" next to the count. Those are coins logged before its pin values were configured — counted, but of unknown value, so they add nothing to the amount. This is a data gap, not missing cash, and it only affects old coins.

Collection thresholds on the report

If collection thresholds are configured for a shop, the report shows them in context:

  • Each location row shows its threshold, and turns red with a Collect tag when the cash in the boxes has reached it.
  • Each machine that has passed its per-machine cap is flagged with an over cap tag.
  • A red banner at the top counts how many locations and machines are currently over.

These flags are the same signal the collection alerts use. What you see marked in red on this report is exactly what will trigger a notification. Setting the thresholds up is covered in the Collection Thresholds guide.

When to use it

  • Planning a collection run — sort by machine, start from the top, and you're always emptying the fullest boxes first.
  • Checking a shop is not overflowing — a quick glance at the by-location totals.
  • Reacting to an alert — the notification links straight here so you can see exactly which machines pushed a shop over its threshold.
