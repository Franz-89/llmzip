A short set of habits that keep the coin numbers accurate and the reports worth trusting. None of it is extra work — it's just doing the collection in the right order.

Introduction

The coin reports are only as good as the collection discipline behind them. The system does the maths for you, but it relies on a few simple things being done consistently. This guide gathers them in one place.

1. Confirm the counter at every collection

The single most important habit. When you empty a machine, read and confirm its counter — don't leave the collection pending.

Why it matters: the moment a counter is confirmed is what the system uses to draw the line between "counted" and "still in the box". A collection that stays pending does not reconcile, and the machine's cash keeps showing as uncounted — so a collection you actually did looks like it never happened.

2. Configure a machine's coin values before it earns

When a machine goes live, make sure each acceptor pin has its money value set. Then every coin it logs carries its worth from the first drop.

Why it matters: a coin logged before its pin value is set has no known value — it counts as a coin but adds nothing to the money. Those "unpriced" coins can't be reconciled and don't count toward collection thresholds. Setting the values up front avoids a blind spot you'd otherwise have to explain later.

3. Collect the fullest boxes first

Use the Cash in Box report, sorted biggest-first, to plan a collection run. You'll always be emptying the machines that need it most, and no box quietly fills to the point of blocking.

Set a per-machine cap. Even if a shop as a whole is nowhere near its threshold, one popular game can fill up on its own. A per-machine cap makes sure that game is flagged for collection long before it blocks — independently of the shop total.

4. Tune thresholds with the report, don't guess

Set your collection thresholds, then watch the Cash in Box report for a week or two and adjust:

  • If nothing ever goes red, the threshold is too high — you're not being warned in time.
  • If everything is always red, it's too low — the alerts become noise and get ignored.

Aim for a level where a red flag genuinely means "worth a trip". Start a little conservative and bring it down as you learn each shop's rhythm.

5. Read a deviation in context

On the reconciliation report, a single collection that's a little off is almost always a miscount — not a problem. What deserves attention is a pattern.

Use the three figures to tell problems apart:

  • Cash below both the counter and the coin log, repeatedly → money going missing. Investigate.
  • Counter disagrees with the coin log, but cash matches the log → the counter or acceptor has drifted, not a cash problem.
  • A one-off gap that doesn't repeat → almost certainly a counting slip.

6. Act on invalid-coin flags

If a machine is flagged for invalid coins — impossible bursts logged in a fraction of a second — treat it as a hardware signal, not a data quirk. It almost always means a bouncing pulse line or a failing acceptor.

Fix the wiring, don't just ignore the number. The system already keeps these phantom coins out of your totals, so your money is correct either way — but the underlying fault means real coins may be miscounted or missed. A machine that keeps doing it is telling you it needs a technician.

7. Only reopen a confirmed collection when you truly need to

Reopening a confirmed collection moves the line the whole system uses to decide what's counted and what's still in the box. Do it for a real correction — not out of habit.

Why it matters: the most recent confirmed collection is what defines each machine's window. Reopen one and the window shifts — money can move between "counted" and "in the box" on the reports until it's confirmed again. That's correct behaviour, but it can look surprising if you didn't expect it, so reopen deliberately.

8. Let the alerts do the remembering

Once thresholds are set and the scheduled check is running, you don't need to keep opening the report "just in case". The system watches every shop and machine and notifies the right people when something needs collecting.

The goal: collections happen because a box is genuinely getting full — not because someone remembered to check, and not because a game already blocked. Get these habits in place and the reports stop being something you inspect and become something you trust.
