How to bring a new terminal from the box to a fully operational device on a game.

Introduction

This guide walks you through the first installation of an IM25/IM30 terminal, from powering it on for the first time to having it fully provisioned and running on a specific game. Most of the work described here is technical and is best performed before the device is physically installed on a game.

A quick word before you start.

These terminals are powerful and capable, and they reward a calm, unhurried approach. Give the install the time it needs, and double-check before confirming any action — a few of the steps here (firmware updates) can't simply be undone from the shop floor, so it's worth getting them right the first time. None of this is difficult; it just deserves your attention.

Base concepts

Before starting, make sure these terms are completely clear. They come up at every step.

IM25 / IM30 — This is the reader and payment terminal.

TID (Terminal ID) — The Terminal ID, which is specific to a single location. A location is tied to a company, so you cannot and must not use the TID of shop A in shop B.

⚠ This is not a formality. Using a TID in the wrong location has legal repercussions. Ignoring this rule can lead to serious legal consequences, including losing the right to operate any device at all. Always confirm the TID belongs to the shop where the device will be used.

PulseBox — This is the PCB that connects to the physical game. The PulseBox and the IM25/IM30 are never physically connected to each other.

Scope of this guide: the PulseBox is mentioned here only so the term is clear. This guide does not cover the PulseBox, and it does not need to be installed to complete this procedure.

The three components you will install

  1. Android / PAX firmware — covered in Part 1.
  2. Integra (Planet) — the payment terminal firmware, covered in Part 2.
  3. SapiensCore app (SmartMonkey) — covered in Part 3.

Before you begin

To perform this first configuration you need to know which shop the device will go to, and you must have a TID available for each device.

What you need before starting:

  • The device and its power supply.
  • A way to get online: a LAN cable or Wi-Fi access (plus a Wi-Fi QR code if you want to use QR activation).
  • The TID for this specific device.
  • The three terminal passwords (see note below).
  • For the final in-shop step only: the NUC on and connected to the same network, and the QR code of the game the device will be installed on.

You will be asked for three different passwords during this process: the installer password, the common password, and the device password. This is simply how the terminal works — each one unlocks a different stage. Make sure you have all three before you start. If you don't have the passwords, you can get them IM25/IM30 — Terminal Passwords (Quick Reference) giving that you have the proper access. If you are denied the access please ask your IT manager.

Stable connection and stable power are mandatory. You need a stable internet connection and a stable power source throughout. Turning the terminal off during a firmware update can permanently block the device.

A permanent block is not something that can be cleared in the shop. The device must be physically shipped back to the payment provider and re-enabled by them on request. This is a requirement of the PCI rules, not a SmartMonkey/Planet/Pax limitation — so it cannot be bypassed.

Part 1 — Power on and internet connection

This step installs and updates the Android / PAX firmware. It runs largely on its own once the device is online.

1a. Power and connectivity

Connect the power supply provided with the device. Then connect the device to the internet using either a LAN cable or Wi-Fi.

Option A — LAN cable

  • Connect a LAN cable to the port at the back of the device labelled lan.

Careful: the device has two RJ45 ports, but only one is named lan on the device. Use that one.

Option B — Wi-Fi

  • Tap the Settings icon.

  • Enter the installer password you were provided.
  • Go to Network & internet. Check that both Wi-Fi and Ethernet are ON, and turn them on if they are not.

    This step is mandatory regardless of which connection type you choose.

  • Open Wi-Fi.
  • Either select a Wi-Fi SSID and type the password, or use the QR code activation (recommended — it is much better).
  • For QR code: you first need a QR-code version of your Wi-Fi ready (the standard Wi-Fi QR-code format, the same one most phones and routers can generate). Select QR code, then move the screen slightly higher so you can clearly see what the device webcam sees. Scan the Wi-Fi code and wait for the device to connect.

If you use Wi-Fi: connect to the same SSID and password used at the shop.

Once connected, a Wi-Fi icon or a LAN connection indicator (depending on your method) appears at the top-right of the screen.

1b. Let the device start up

Exit this menu using the square icon at the bottom-right, then exit Settings. The device will now begin its operations in the background.

To confirm you are online and to push the device to start immediately, open the MaxStore app. If apps load on the screen, everything is fine up to this point.

 

If you get an error:

  • A timeout → the device is not connected to the internet.
  • An error showing the IM25 Serial Number → this indicates a configuration issue at a higher level. Note down the full error (including the Serial Number) and request assistance from SmartMonkey.

During installation/update the device may show several screens. You don't have to do anything. Even prompts that look like questions are answered correctly by the device itself within a short time.

1c. When Part 1 is complete

This first step ends when the device displays the following screen:

Invalid terminal configuration: Please download a configuration.

HID: <terminal Serial Number>
TID: 0000000000  (or ZZZZZZZZZZ)

Below the message you should see a HID: followed by the terminal Serial Number, and a TID: showing all zeros. Sometimes it shows all Z's (for example ZZZZZZZZ) instead of zeros — this means the same thing.

Note: if the TID shows a real number (anything other than all zeros or all Z's), check the status of this terminal with SmartMonkey. Virgin terminals usually do not have a pre-installed TID. Occasionally it can happen because terminals are randomly tested before shipping — that is not a problem.

The device is now ready to download the second configuration: the one for the payment integration.

Part 2 — Integra (Planet) firmware

This step downloads the Integra firmware from Planet, the payment processor, and binds the device to its TID.

  1. Long-tap on the Planet logo.
  2. Enter the common password.
  3. Follow: Config → Update → Firmware.
  4. The first screen asks for a TMS IP / DNS. Do not change this value — it is set automatically. Tap the green button to continue.
  5. The next screen asks for the TMS port. Again, do not change it — it is configured automatically. Tap the green button to continue.
  6. Now enter the TID you were provided.

Enter every digit of the TID. Many TIDs start with one or more zeros, for example 00139123. You must enter all the digits. Double-check the number is correct before continuing.

  1. Tap the green button to continue.

The device will start downloading the Integra firmware (Planet, the payment processor). It may or may not reboot, depending on its status. No action is needed — simply wait. This can take from a few seconds to a few minutes.

Part 2 is complete when the screen shows a large Planet logo, with the TID you entered written at the bottom and the shop's name below it.

Notice that at no point did you type the shop's name. This is because the TID is already connected to a specific shop beforehand.

Moving a device to a different shop: you will need to unbind it from this TID and rebind it to a new/different TID. An unbound TID can be reused without any issue. However, at any given moment a TID can be used in one device and one device only — otherwise it simply will not work. A separate guide for the unbinding procedure will follow soon.

Part 3 — Install the SapiensCore app

Congratulations — you are now ready to install the SapiensCore app.

  1. Long-tap on the logo again.
  2. Enter the common password you were provided.
  3. Follow: Config → System → Go to the Launcher (it is the very last option).
  4. Now, quickly, long-tap again on the Planet logo. The terminal will prompt you for the device password you were provided. Enter it and tap the green button.
  5. Scroll down in the new menu and tap Open PAX Launcher.
  6. Check whether SapiensCore is already installed. If it is, skip ahead to step 11 (Open). If it is not, continue:
  7. Open MaxStore.
  8. Scroll down until you see the SapiensCore app. Note: the store listing name may differ from "SapiensCore" — at the moment it appears as Sould Park. It is the correct app regardless of the listing name.
  9. Tap Get, then Install.
  10. Wait for the installation to complete.
  11. Tap Open.
  12. The app will ask you to enter the same TID as the device. Be very careful and double-check you are entering the right TID.
  13. Type the TID and select OK.

Provisioning

SapiensCore will now collect all the relevant information and perform the terminal provisioning. The device will show a QR code. If everything goes well, you can ignore it and simply wait — we pre-authorise devices based on their Serial Number.

SapiensCore may decide to reboot the device on its own. This is normal and, in some cases, expected — it happens when the device's operational mode is something other than Arcade. No action is needed; let the device finish.

If a yellow message appears: "Device is in installation mode. Please contact support." → send a message to SmartMonkey with the Serial Number and TID shown on the device screen. If you take a picture, make sure it is clear and in focus.

SapiensCore will send the correct configuration for this device, including the Wi-Fi SSID and password if you did the configuration over LAN. A counter will appear on screen, counting down from 10 to 0. At 0, the on-screen configuration is applied. The terminal shows which SSID, Wi-Fi password, auth server and domain the device will connect to.

If all is well, a Config Saved message appears.

Two options will appear: Reboot and Shutdown. Both lead to the same final configuration — the only difference is the power cycle:

  • Choose Reboot if you are already in the shop, the device is installed on its game, and the NUC is ready. The device comes straight back up, ready for the final step — no need to shut down and power on again.
  • Choose Shutdown if you are not finishing now (for example, the device still has to be transported and installed on the game). You will power it on again at the shop to do the final step.

The final configuration can only be completed when all of the following are true:

  • the device is in the shop and physically installed on the game;
  • the QR code of that specific game (the one the device is installed on) is available;
  • the NUC is on, ready, and connected to the same network as the device.

Part 4 — Final configuration on a specific game

This last step is performed in the shop, after the device is physically installed on the game. You reach it either by choosing Reboot in the previous step (the device comes straight back up) or by powering the device on after a Shutdown — either way, the device starts up and SapiensCore launches on its own.

  1. If you chose Shutdown earlier, turn the device on now. SapiensCore starts automatically within a few seconds (if you rebooted, it is already starting).
  2. If the device is not yet configured for a specific game, a QR code appears.
  3. Scan the QR code and follow the link. It brings you into your SapiensCore instance. Log in if needed.
  4. The page asks you to select the location of this terminal and the specific game. Select both and tap Save.

Done. Within about 30 seconds the device is approved and the final configuration is installed. The terminal is now operational.
