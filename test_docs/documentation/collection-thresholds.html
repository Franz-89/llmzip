Get notified before a shop's cash builds up too much or a game gets blocked, by setting the amount at which a collection should be triggered.

Introduction

Collection thresholds turn the Cash in Box snapshot into an early warning. You decide how much uncounted cash is "too much" — for a whole shop, and optionally for any single machine — and the system notifies the shop's users when that amount is reached, so they can collect in time.

Two independent triggers:

  • Location threshold — alert when the total cash across all a shop's machines reaches this amount.
  • Per-machine cap — alert when any single machine reaches this amount, so a busy game never fills up and blocks, even if the shop as a whole is nowhere near its threshold.

A good example: a shop's location threshold might be a large round number, while the per-machine cap is much smaller — so a single popular game that fills quickly gets collected on its own, long before the shop total would ever trigger.

Base concepts

Owner default — The thresholds that apply to all of an owner's shops unless a shop says otherwise. This is where you set the general policy.

Location override — A specific shop can override any of the values — enable/disable, its own location threshold, its own per-machine cap. Anything a shop doesn't override falls back to the owner default.

How a value is chosen: the system starts from the owner default and then applies any location override on top, field by field. So you set the policy once for the owner, and only touch individual shops that need to differ.

Setting the owner default

Open Location → Collection Thresholds. Choose the owner, then set:

  • Enable collection alerts — the master switch. If this is off, nothing is checked and no one is notified.
  • Location threshold — the shop-total amount. Leave it at 0 to switch off the shop-level trigger.
  • Per-machine cap — the single-machine amount. Leave it at 0 to switch off the per-machine trigger.

Save, and the default is in force for every shop under that owner.

A threshold of 0 means "off" for that level. You can run only the shop-total trigger, only the per-machine cap, or both. Turning the master switch off disables everything at once without losing your numbers.

Seeing it on the report

Everything you configure is reflected live on the Cash in Box report: the location threshold appears next to each shop, a shop that has reached it turns red with a Collect tag, and any machine over its cap is flagged over cap. This is the quickest way to check your thresholds are set sensibly — if nothing ever goes red, they may be too high; if everything is red, too low.

How the alerts are sent

A scheduled check runs on its own in the background. Each time it runs it looks at the current Cash in Box state and, for every shop that is over its location threshold or has machines over the cap, it notifies that shop's users. The notification links straight to the Cash in Box report so they can see exactly what to collect.

You won't be spammed. A shop that has just been alerted is not alerted again for a while, even if the check runs frequently. It waits out a quiet window before it can notify the same shop again — so a shop that stays over threshold produces one alert, not one every run.

Once it's set up, it looks after itself. Configure the thresholds, and from then on the right people get a nudge whenever a shop or a machine needs collecting — no one has to remember to check.

Unpriced coins and thresholds

Thresholds work on known money. Coins logged before a machine's values were configured count as coins but not as money, so they don't push a shop over its threshold. Once a machine's pins are configured, every new coin carries its value and counts normally. If a shop seems oddly low against its threshold, check whether it still has old unpriced coins on the Cash in Box report.
